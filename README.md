# LEAP Estates × Sail

A clickable concept for a **date-of-death property valuation** arriving on the Assets → Properties
card in LEAP's Estate Administration app, the ancillary services that follow it, and the report
that comes back.

Open it: <https://westartfires.github.io/leap-sail-valuation-demo/>

## What it is

Front-end only. No framework, no build step, no npm — open the folder on a static server and it
runs.

**Nothing here talks to a live system.** Every person, address, title number, matter number and
figure in the concept is invented, and the API panel replays canned responses in the real response
shapes rather than calling anything. The photographs in the report are real marketing photographs
of a house Sail handled, used to show what the document looks like; the address printed over them
is not that house.

The LEAP screens are our reconstruction, drawn from LEAP's published screenshots and the LEAP
University curriculum rather than traced from the product. LEAP's brand fonts are not publicly
licensed, so system faces stand in.
